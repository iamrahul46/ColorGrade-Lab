## ✦ About

**ColorGrade Lab** is an interactive learning environment built around the
principles of professional digital color grading.

Instead of learning color correction only through tutorials and theory,
ColorGrade Lab allows users to explore grading concepts visually and
understand how individual tools affect an image.

The project combines:

- 🎨 Color correction
- 🎛️ Interactive grading controls
- 📈 Scopes
- 🧩 Node-based workflows
- 🎯 Secondary corrections
- 🖼️ Reference and still comparison
- 🤖 AI-assisted image analysis
- 🎥 Cinematic look development

## 🎛️ Color Tools

### Primary Controls

| Tool | Purpose |
|---|---|
| **Lift** | Control shadow regions |
| **Gamma** | Shape midtones |
| **Gain** | Control highlights |
| **Offset** | Adjust overall image balance |
| **Contrast** | Control tonal separation |
| **Pivot** | Change contrast around a tonal pivot |
| **Temperature** | Control warm / cool balance |
| **Tint** | Correct green / magenta bias |
| **Saturation** | Control overall color intensity |
| **Color Boost** | Increase weaker colors selectively |
| **Midtone Detail** | Control perceived midtone definition |
| **Shadows** | Shape darker tonal regions |
| **Highlights** | Shape brighter tonal regions |
| **Luminance Mix** | Balance luminance influence |

## 🧰 Professional Tools

### 🎨 Color Wheels

Interactive Lift, Gamma, Gain and Offset wheels for understanding
how tonal regions respond to color adjustments.

### 📈 Curves

Explore targeted tonal and chromatic manipulation through:

- Hue vs Hue
- Hue vs Saturation
- Hue vs Luminance
- Luminance vs Saturation
- Saturation vs Saturation

### 🎯 Qualifier

Learn how secondary color selections isolate specific regions of an image.

### ⬡ Power Windows

Understand how shapes can isolate subjects, faces and areas of the frame.

### 🎯 Tracker

Explore subject tracking and how windows can follow movement.

### 🧩 Nodes

Understand how professional grades are constructed using a node-based workflow.

### 🖼️ Gallery

Compare reference stills and grading results.

### 🎞️ LUTs

Understand LUT application, intensity and creative transformation.

### 🎚️ RGB Mixer

Explore channel mixing and RGB relationships.

### 📊 Scopes

Study image data using:

- Waveform
- RGB Parade
- Vectorscope
- Histogram

The workflow can evaluate:

- Exposure
- White balance
- Contrast
- Shadow clipping
- Highlight clipping
- Saturation
- Color bias
- Skin tones
- Image resolution
- Overall image characteristics
